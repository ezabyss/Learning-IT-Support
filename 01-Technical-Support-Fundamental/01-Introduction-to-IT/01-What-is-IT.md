# 1 What is Information Technology (IT)?

## ✅ Definition
Information Technology (IT) is the use of digital technology (computers, internet, networks) to store, process, transmit, and manage data into useful information.

---

## 🧠 Break It Down

Data = Raw facts  
Information = Processed, meaningful data  
IT = Systems that transform data into information  

🌍 Real World Example:

Raw Data:
    Temperature: 39.2
    Heart Rate: 115

Processed Information:
    Patient has fever and elevated heart rate.

Medical monitoring systems = IT in action.

#  The Digital Divide

## 📌 Definition
The Digital Divide is the gap between:
- People with access to technology & digital skills
- People without access

## Causes:
- Socio-economic factors
- Geography
- Education inequality
- Infrastructure limitations

🌍 Real World Example:

Student A:
- High-speed internet
- Personal laptop
- Coding classes

Student B:
- Shared library computer
- Limited access
- No technical exposure

Skill gap widens over time.

IT professionals help bridge this gap.

---

## 🔧 Standard Troubleshooting Flow

1. Identify the problem
2. Establish a theory
3. Test the theory
4. Implement the solution
5. Verify full functionality
6. Document everything

🌍 Real Example:

User cannot access internet.

Check IP:
    ipconfig

Ping router:
    ping 192.168.1.1

If needed:
- Restart service
- Check cables
- Verify switch

Problem solved.

- Scripts fail
