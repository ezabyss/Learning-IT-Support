# 📘 Power Supply and Electricity Basics
## How Computers Get and Use Power

---

# 1️⃣ Why Power Matters

A computer cannot function without electricity.

The **Power Supply Unit (PSU)** is responsible for:

- Supplying power to all components
- Converting electricity into usable form
- Distributing power safely

---

# 2️⃣ AC vs DC Power

## 🔹 AC (Alternating Current)

- Comes from wall outlets
- Changes direction constantly
- High voltage

---

## 🔹 DC (Direct Current)

- Used by computers
- Flows in one direction
- Low, stable voltage

---

## 🧠 Key Concept

```
Wall → AC power
Computer → needs DC power
```

---

# 3️⃣ Role of the Power Supply (PSU)

The PSU:

- Converts AC → DC
- Reduces voltage to safe levels
- Sends power to:
  - Motherboard
  - CPU
  - GPU
  - Storage devices

---

# 4️⃣ Components of a Power Supply

Typical PSU includes:

- Cooling fan (prevents overheating)
- Voltage label (specifications)
- Power cables (connect components)
- Power input socket

---

# 5️⃣ Understanding Electricity (Water Analogy)

Think of electricity like **water in pipes**.

| Concept | Water Analogy | Electricity |
|--------|---------------|------------|
| Pressure | Water pressure | Voltage (Volts) |
| Flow | Water flow rate | Current (Amps) |
| Power | Total water output | Wattage (Watts) |

---

# 6️⃣ Voltage (V)

## 📌 Definition

Voltage = Electrical pressure

It **pushes electricity** through a circuit.

---

### ⚠ Real World Example

Plugging a:

```
120V device → 220V outlet
```

Result:

- Too much voltage
- Device gets damaged or destroyed

---

### Opposite Case

```
220V device → 120V outlet
```

Result:

- Device works poorly or slowly
- May not function properly

---

🧠 Rule:

Always match the correct voltage.

---

# 7️⃣ Current / Amperage (A)

## 📌 Definition

Current (amps) = Flow of electricity

It represents how much electricity is being **pulled**.

---

### Example

Charger ratings:

```
1A charger → slower charging
2.1A charger → faster charging
```

More amps = more current flow

---

# 8️⃣ Wattage (W)

## 📌 Definition

Wattage = Total power used

Formula:

```
Watts = Volts × Amps
```

---

## 🧠 Key Idea

- Voltage = pushes electricity
- Current = pulls electricity
- Wattage = total power consumption

---

# 9️⃣ Choosing the Right Power Supply

If PSU wattage is too low:

- Computer won’t start
- Components may fail

---

## 🔹 Typical Power Usage

| Usage Type | PSU Recommendation |
|------------|------------------|
| Basic use (browsing) | 300–500W |
| Gaming / editing | 600–800W+ |
| High-end workstation | 800W+ |

---

## 🧠 Important Insight

Having a higher watt PSU is **safe**.

The PSU only supplies what the system needs.

---

# 🔟 Common Power Supply Issues

Power supplies can fail due to:

- Overheating
- Power surges
- Lightning strikes
- Component wear
- Burnouts

---

## 🔹 Symptoms of PSU Failure

- Computer won’t turn on
- Random shutdowns
- Burning smell
- No fan movement

---

# 1️⃣1️⃣ Real World IT Scenario

User says:

"Computer is not turning on"

---

### Troubleshooting Steps:

1. Check power cable
2. Check outlet
3. Test PSU
4. Look for LED indicators
5. Replace PSU if needed

---

# 🧠 Memory Cheat Sheet

```
AC → wall power
DC → computer power

Voltage (V) = pressure
Current (A) = flow
Wattage (W) = total power

W = V × A
```

---

# 🎯 Key Takeaways

1. Computers require DC power.
2. PSU converts AC → DC.
3. Voltage pushes electricity.
4. Current pulls electricity.
5. Wattage represents total power.
6. Wrong voltage can damage devices.
7. PSU issues are a common hardware problem.

---

# 🚀 Big Picture

The power supply is the **lifeline of a computer**.

Without stable and correct power:

- Components fail
- Systems crash
- Data can be lost

Understanding electricity helps IT professionals:

- Prevent hardware damage
- Diagnose failures quickly
- Build reliable systems
