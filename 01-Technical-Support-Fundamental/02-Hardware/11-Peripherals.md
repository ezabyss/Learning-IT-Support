# 📘 Peripherals, USB, Display & Connector Types
## Complete Guide for IT Support

---

# 1️⃣ What Are Peripherals?

## 📌 Definition

A **peripheral** is any external device connected to a computer to add functionality.

---

## 🔹 Examples

- Keyboard ⌨️  
- Mouse 🖱️  
- Monitor 🖥️  
- Printer 🖨️  
- USB drives 💾  
- Headphones 🎧  

---

## 🧠 Key Idea

```
Peripheral = External device that extends computer capability
```

---

# 2️⃣ USB (Universal Serial Bus)

## 📌 What is USB?

USB is the **most common connector** used for:

- Data transfer
- Power delivery

---

# 3️⃣ USB Versions (Speed Comparison)

| Version | Color | Speed |
|--------|------|------|
| USB 2.0 | Black | 480 Mbps |
| USB 3.0 | Blue | 5 Gbps |
| USB 3.1 | Teal | 10 Gbps |

---

## ⚠ Important Concept

```
Mb/s ≠ MB
```

- Mb/s = Megabits per second (speed)
- MB = Megabytes (storage)

---

## 🔹 Conversion Rule

```
1 Byte = 8 bits
```

Example:

```
8 Mb/s = 1 MB/s
```

---

# 4️⃣ USB Compatibility

USB is **backward compatible**.

---

## 🔹 Example

```
USB 3 device + USB 2 port → works at USB 2 speed
```

---

## 🧠 Key Idea

Speed depends on:

- Cable
- Port
- Device

---

# 5️⃣ Modern USB Connectors

---

## 🔹 Micro USB

- Small connector
- Older Android devices

---

## 🔹 USB-C

- Reversible
- High speed + power + display

Speed:

```
Up to 20 Gbps
```

---

## 🔹 USB4 (Thunderbolt)

- Uses USB-C
- Extremely fast

Speed:

```
Up to 40 Gbps
```

---

## 🔹 Lightning (Apple)

- Apple-only connector
- Charging + data + display

---

# 6️⃣ Display Connectors

---

## 🔹 DVI

- Video only
- No audio

---

## 🔹 HDMI

- Video + Audio
- Common in TVs and monitors

---

## 🔹 DisplayPort

- Video + Audio
- High performance

---

## 🔹 USB-C

- Data + Power + Video

---

## 🧠 Key Comparison

| Connector | Audio | Video |
|----------|------|------|
| DVI | ❌ | ✔ |
| HDMI | ✔ | ✔ |
| DisplayPort | ✔ | ✔ |
| USB-C | ✔ | ✔ + Data + Power |

---

# 7️⃣ Communication Connectors (Networking)

---

## 🔹 POTS (Telephone)

- Old phone systems
- Connector:

```
RJ-11
```

---

## 🔹 DSL

- Internet via phone lines
- Uses:

```
RJ-45 (Ethernet)
```

---

## 🔹 Cable Internet

- Uses TV cables

Connector:

```
F-type
```

---

## 🔹 Fiber Optic

- Uses light
- Very fast
- Long-distance communication

---

# 8️⃣ Legacy Connectors

---

## 🔹 DB9

- Old connector
- Used for:
  - Keyboard
  - Mouse
  - Joystick

---

## 🔹 Molex

- Internal power connector

Used for:

- Hard drives
- Optical drives
- GPUs (older systems)

---

# 9️⃣ Punch Down Blocks

## 📌 Definition

Used to connect:

- Telephone lines
- Network cables (LAN)

---

## 🔹 Purpose

- Organize wiring
- Easy connections
- Quick troubleshooting

---

# 🔟 Real World IT Scenarios

---

## 🔧 Scenario 1: Slow File Transfer

Cause:

- USB 3 device plugged into USB 2 port

Fix:

- Use USB 3 port (blue)

---

## 🔧 Scenario 2: No Audio on Monitor

Cause:

- Using DVI cable

Fix:

- Use HDMI or DisplayPort

---

## 🔧 Scenario 3: No Internet

Check:

- RJ-45 cable
- Router/modem
- Fiber or cable connection

---

# 🧠 Memory Cheat Sheet

```
Peripheral = external device

USB = data + power

USB speeds:
2.0 = 480 Mbps
3.0 = 5 Gbps
3.1 = 10 Gbps

1 Byte = 8 bits

RJ-45 = internet
RJ-11 = phone

HDMI = audio + video
DVI = video only
```

---

# 🎯 Key Takeaways

1. Peripherals expand computer functionality.
2. USB is the most common connector.
3. USB versions differ in speed.
4. Mbps ≠ MB (speed vs storage).
5. HDMI and DisplayPort support audio + video.
6. RJ-45 is used for networking.
7. Fiber is the fastest communication medium.
8. Legacy connectors still exist in IT environments.
9. Punch down blocks organize network wiring.

---

# 🚀 Big Picture

Connectors are the **foundation of communication** in computing.

They allow:

- Devices to connect
- Data to flow
- Systems to interact

Understanding connectors helps IT professionals:

- Troubleshoot faster
- Build systems correctly
- Support users effectively

Technology evolves, but the **core idea remains the same:**

👉 Connect → Communicate → Function
